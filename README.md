# D-TOPS Signal Analysis (Isotropic Free Thermal Expansion Model)

Python implementation for analyzing Frequency-Domain Photothermal Beam Deflection (D-TOPS / FDPBD) measurements on metal-coated bulk samples using an isotropic free thermal expansion model.

This software fits the bulk material's thermal conductivity ($\lambda$) and (optionally) its coefficient of thermal expansion (CTE, $\alpha_T$) from measured in-phase and out-of-phase probe beam deflection signals across a modulation frequency range.

---

## Physical Model Overview

The model calculates the complex probe deflection angle $\theta(f)$ as a function of modulation frequency $f$ by summing up to three physical contributions:

1. **Thermoelastic Surface Deformation**:
   - Dynamic surface swelling caused by local thermoelastic expansion in the bulk substrate.
   - Evaluated using the temperature at the top of the bulk substrate ($T_{bs}$), derived from surface temperature ($T_s$) by accounting for interface thermal conductance ($G_{int}$) and heat conduction through the metal coating matrix.
2. **Air Lens Mirage Effect** *(Optional)*:
   - Probe beam deflection caused by thermal index gradients ($dn_{\text{air}}/dT$) in the air/gas layer adjacent to the heated sample surface.
3. **Fresnel Reflection Phase Shift** *(Optional)*:
   - Phase and angle changes induced in the reflected probe beam due to temperature-dependent refractive index changes in the sample.

### Thermal Transport & Heating

- **Multilayer Heat Diffusion Solver**: Uses a bidirectional FDTR model in frequency and wavevector domain to calculate local complex surface temperatures $T_s(k, f)$ across multilayer stacks (fluid layer above, metal film, interface layer, bulk substrate below).
- **Steady-State DC Heating**: Computes steady-state (DC) temperature rise ($T_{\text{ss}}$) generated by absorbed pump and probe laser beams to monitor thermal load during measurements.

## Module Architecture

The repository is modularized as follows:

| Module | Description |
|---|---|
| `main.py` | Main execution script. Handles CLI arguments, optics/sample parameter configuration, lock-in data loading, leaking response correction, frequency trimming around out-of-phase peak $f_c$, model fitting, logging, and plotting. |
| `data_io.py` | Data loader and signal correction routines. Parses 4-column lock-in files (`get_data_out_in_ratio_f_vsum`) and corrects complex voltage signals for pump-modulation and detector response (`datacorrection_complex_leaking`). |
| `heat_diffusion.py` | Thermal transport calculations. Implements bidirectional multi-layer frequency-domain heat transfer (`bifdtr_bo_temp`) and DC steady-state surface temperature estimation (`ss_heat`). |
| `deflection_model.py` | Physics core (`theta_iso_free_thermal_expansion_model`). Integrates thermoelastic, air-lens, and reflection contributions over wavevector $k$-space using Gauss-Legendre quadrature. |
| `fitting.py` | Non-linear optimization routines (`fit_inout` for dual $\lambda + \alpha_T$ fitting and `fit_ratio` for ratio $\lambda$ fitting) using `scipy.optimize.least_squares` with error/confidence interval estimates. |

## Input Data Format

Raw experimental lock-in data must be provided as a whitespace- or tab-delimited text file (`.txt`) with **4 headerless columns**:

| Column | Parameter | Description |
|---|---|---|
| Column 1 | `V_in` | Lock-in in-phase voltage signal [V] |
| Column 2 | `V_out` | Lock-in out-of-phase voltage signal [V] |
| Column 3 | `f` | Modulation frequency [Hz] |
| Column 4 | `V_SUM` | Total sum voltage on detector [V] |

### Signal Preprocessing & Frequency Response Correction

Raw voltage signals are corrected for system frequency response ("leaking") using a calibrated complex transfer function polynomial:

$$V_{\text{corrected}} = \frac{V_{\text{in}} + i V_{\text{out}}}{\text{complex\_leaking}(f)}$$

Data points are automatically trimmed around the out-of-phase peak frequency $f_c$ (retaining frequencies within $f_c/10$ to $10 f_c$) to optimize signal-to-noise ratio during fitting.

## Parameters & Configuration

All physical properties and setup parameters are configured within `main.py`:

### 1. Sample & Layer Properties
- `lambda_down`: List of cross-plane thermal conductivities $[\lambda_{\text{metal}}, \lambda_{\text{interface}}, \lambda_{\text{bulk}}]$ (W/m·K).
- `eta_down`: Thermal conductivity anisotropy ratios ($k_x/k_y$) for each layer.
- `C_down`: Volumetric heat capacities $[C_{\text{metal}}, C_{\text{interface}}, C_{\text{bulk}}]$ (J/m³·K).
- `h_down`: Layer thicknesses $[h_{\text{metal}}, h_{\text{interface}}, h_{\text{bulk}}]$ (m).
- `niu`: Poisson's ratio ($\nu$) of the bulk substrate.
- `alpha_T`: Initial estimate / seed value for bulk substrate CTE ($\alpha_T$) (1/K).

### 2. Gas / Ambient Medium Properties
- `lambda_up`, `C_up`, `h_up`, `eta_up`: Thermal conductivity, volumetric heat capacity, thickness, and anisotropy of ambient gas/medium above the sample (e.g., air).

### 3. Optics & Experimental Setup
- `obj`: Objective lens magnification.
- `focal_length`: Effective focal length of the objective lens (m).
- `lens_transmittance`: Lens optical transmittance.
- `r_rms`: Focused pump and probe 1/e² Gaussian beam radius (m).
- `xoffset`: Spatial offset between pump and probe beam centers (m).
- `C_probe`: Probe factor / beam geometry scaling factor.
- `w_1_d`: Probe 1/e² radius at the detector plane (m).
- `incident_pump`, `incident_probe`: Incident laser powers before lens (W).
- `n_metal`, `k_metal`: Complex optical constants of the metal coating used to calculate absorbance and effective pump power ($A_{\text{pump}}$).

### 4. Physical Contributions & Model Toggles
- `air_lens`: Dictionary `{'enable': True/False, 'coef_air': float}` to toggle the air mirage effect.
- `reflection`: Dictionary `{'enable': True/False, 'wavelength': float, 'dphidT': float}` to toggle thermo-reflective phase shift contributions.

### 5. Fitting Mode Selection
- `FDPBD_fitting1 = True`: Fits **both** bulk thermal conductivity ($\lambda_{\text{bulk}}$) and CTE ($\alpha_T$) simultaneously from in-phase and out-of-phase deflection signals.
- `FDPBD_fitting2 = True`: Fits bulk thermal conductivity ($\lambda_{\text{bulk}}$) **only** using the signal ratio ($-V_{\text{in}} / V_{\text{out}}$).

## Usage

### Basic Execution

Run analysis on the default dataset defined in `main.py`:

```bash
python main.py
```

### Specifying Custom Data Files

Pass a custom data text file as a positional argument or via `--file`:

```bash
python main.py path/to/sample_data.txt
```

or:

```bash
python main.py --file DTOPS_AlCaF2_10x_1p0-1p0_100k-100_313p2mV.txt
```

### Options

- **Save Output Data Curves**: Save processed experimental data and fitted model predictions to `test.dat`:
  ```bash
  python main.py --save
  ```
- **Headless Mode**: Disable interactive matplotlib plot generation (useful for automated scripts):
  ```bash
  python main.py --no-plot
  ```

---

## Output Files

1. **Console Output**: Prints estimated steady-state heating, fitted bulk thermal conductivity ($\lambda$) with standard uncertainty, fitted CTE ($\alpha_T$) with standard uncertainty, and final post-fit steady-state heating.
2. `results.dat`: Tab-separated record containing:
   - `filename`: Source dataset name
   - `fitted_thermal_conductivity`: Fitted bulk thermal conductivity (W/m·K)
   - `uncertainty_thermal_conductivity`: Standard error of thermal conductivity
   - `fitted_CTE`: Fitted coefficient of thermal expansion (1/K)
   - `uncertainty_CTE`: Standard error of CTE
3. `test.dat` *(Generated when `--save` is used)*: 8-column ASCII table containing:
   - Column 1: Frequency $f$ [Hz]
   - Column 2: Detector sum voltage $V_{\text{SUM}}$ [V]
   - Column 3: Experimental in-phase deflection $\theta_{\text{exp, in}}$ [rad]
   - Column 4: Experimental out-of-phase deflection $\theta_{\text{exp, out}}$ [rad]
   - Column 5: Experimental ratio signal $(-\theta_{\text{exp, in}} / \theta_{\text{exp, out}})$
   - Column 6: Model fitted in-phase deflection $\theta_{\text{model, in}}$ [rad]
   - Column 7: Model fitted out-of-phase deflection $\theta_{\text{model, out}}$ [rad]
   - Column 8: Model fitted ratio signal
